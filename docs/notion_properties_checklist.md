# Notion Properties - Quick Checklist

## Properties to Add to Learnings Database

Open your Learnings database in Notion and add these 5 properties:

### ✅ Checklist

- [ ] **Usage Count**
  - Type: Number
  - Format: Number
  - Default: 0

- [ ] **Helpful Rate**
  - Type: Number
  - Format: Number (or Percent)
  - Default: 0

- [ ] **Success Rate**
  - Type: Number
  - Format: Number (or Percent)
  - Default: 0

- [ ] **Last Used**
  - Type: Date
  - Include time: ✓ Yes
  - Allow empty: ✓ Yes

- [ ] **Effectiveness Score**
  - Type: Number
  - Format: Number (2 decimals)
  - Default: 0

## Quick Add Steps

For each property:
1. Click `+` in table header
2. Name it exactly as shown above
3. Select type
4. Configure format
5. Save

## Verification

After adding all properties, you should see them as columns in your Learnings database table view.
